# Oluwademilade Somide — Portfolio Website

A fully responsive, production-ready personal portfolio website showcasing my work as a Data Scientist.

🔗 **Live Site:** [demisomi.github.io](https://demisomi.github.io)


---

## 🛠️ Built With

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Outfit, Source Serif 4)

No frameworks. No dependencies. Just clean, hand-coded frontend.

---

## 📁 Project Structure

```
├── index.html          # Main page
```

## 🚀 Getting Started

### View Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/demisomi/demisomi.github.io.git
   ```

2. Open `index.html` in your browser

## 📝 Sections

- **Hero** — Introduction and call-to-action
- **About** — Background and personal info
- **Experience** — Work history timeline
- **Projects** — Featured work with tech stacks
- **Skills** — Technical skills organized by category
- **Education** — Academic background
- **Contact** — Email and social links
